# Task Manager CRUD API

A simple RESTful task-management API built with Python and FastAPI. It provides
CRUD operations for tasks and stores data in memory while the application is
running.

## Features

- Create a task with a title and completion status.
- List all tasks.
- Retrieve one task by ID.
- Update a task.
- Delete a task.
- Check API health.
- Explore the interactive API documentation generated by FastAPI.

## Requirements

- Python 3.9 or newer

## Setup and Run

1. Create and activate a virtual environment (recommended):

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the development server:

   ```bash
   uvicorn main:app --reload
   ```

The API is available at `http://127.0.0.1:8000`.

Interactive documentation is available at:

- Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc: `http://127.0.0.1:8000/redoc`

## API Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/` | Returns the API version and available endpoint groups. |
| `GET` | `/health` | Returns the API health status. |
| `POST` | `/tasks` | Creates a new task. |
| `GET` | `/tasks` | Returns all tasks. |
| `GET` | `/tasks/{task_id}` | Returns one task by ID. |
| `PUT` | `/tasks/{task_id}` | Updates a task by ID. |
| `DELETE` | `/tasks/{task_id}` | Deletes a task by ID. |

## Request Examples

Create a task:

```bash
curl -X POST http://127.0.0.1:8000/tasks \
  -H "Content-Type: application/json" \
  -d "{\"title\":\"Learn FastAPI\",\"completed\":false}"
```

Example response:

```json
{
  "id": 1,
  "title": "Learn FastAPI",
  "completed": false
}
```

Update a task:

```bash
curl -X PUT http://127.0.0.1:8000/tasks/1 \
  -H "Content-Type: application/json" \
  -d "{\"completed\":true}"
```

Delete a task:

```bash
curl -X DELETE http://127.0.0.1:8000/tasks/1
```

## Validation and Errors

- A task must include a non-empty `title` when it is created.
- Missing task IDs return `404 Not Found`.
- Invalid task creation requests return `400 Bad Request`.

## Storage Limitation

Tasks are stored in a Python list, so all data is lost whenever the server
restarts. This implementation is intended for learning and demonstration.
A production version should use a persistent database such as PostgreSQL or
SQLite.
